# 🎓 AI Career Advisor

An intelligent web application that helps students and job seekers explore suitable career paths based on their interests, skills, and educational background.

## 📌 Overview

Choosing the right career can be challenging. The **AI Career Advisor** is a responsive web application that provides personalized career recommendations by analyzing user inputs such as interests, skills, education level, and career preferences.

The project is designed to guide users toward careers that align with their strengths while presenting detailed information about each suggested career.

A modern, responsive, glassmorphism-styled web app that takes a list of your skills and charts a career path: matched roles, a skill-gap breakdown, and a staged learning roadmap — all generated client-side, with a one-click PDF report export.

![License: MIT](https://img.shields.io/badge/license-MIT-informational)

## ✨ Features

- **Skill input dashboard** — add skills as tags, with quick-add suggestion chips and comma-separated paste support
- **AI-style recommendation engine** — a transparent weighted-scoring match against a curated career database (no external API, runs instantly in-browser)
- **Career suggestions grid** — ranked cards with animated match-percentage rings and matched-skill highlighting
- **Learning roadmap** — staged, time-boxed plan specific to your top-matched role
- **Skill gap chart** — visual comparison across your top matches
- **Downloadable PDF report** — full analysis exported client-side via [jsPDF](https://github.com/parallax/jsPDF), no server round-trip
- **Dark / light mode** — toggle with persisted preference, respects `prefers-color-scheme`
- **Glassmorphism UI** — translucent panels, aurora-gradient accents, animated constellation visuals
- **Fully responsive** — mobile-first layout, down to small phones
- **Accessible** — keyboard-navigable, visible focus states, `aria-live` announcements, respects `prefers-reduced-motion`
- **Zero build step** — plain HTML/CSS/JS, deploy as static files anywhere

---

## 📁 Project structure

```
ai-career-advisor/
├── index.html        # Page structure & markup
├── style.css          # Design system, glassmorphism, themes, responsive layout
├── script.js          # Matching engine, rendering, theme toggle, PDF export
├── careerData.js       # Career & skill knowledge base (edit this to extend)
└── README.md
```

No `node_modules`, no bundler, no build step. Open `index.html` in a browser and it works.

## 🚀 Run locally

Just open the file:

```bash
open index.html        # macOS
start index.html        # Windows
xdg-open index.html      # Linux
```

Or serve it (recommended, avoids any local file:// quirks with fonts/scripts):

```bash
# Python 3
python3 -m http.server 8000

# Node (if you have npx)
npx serve .
```

Then visit `http://localhost:8000`.

## 🌐 Deploy to GitHub Pages

1. Push this folder to a GitHub repository (root of the repo, or a `/docs` folder — your choice).
2. In your repo: **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **Deploy from a branch**.
4. Pick the branch (usually `main`) and the folder (`/root` or `/docs`).
5. Save. GitHub will give you a URL like `https://<your-username>.github.io/<repo-name>/` within a minute or two.

That's it — no build pipeline needed since this is a static site.

### Using `gh-pages` CLI (optional alternative)

```bash
npm install -g gh-pages
gh-pages -d .
```

---

## 🧠 How the matching works

`careerData.js` defines a list of careers, each with:

- `coreSkills` — heavily weighted in scoring
- `niceToHave` — lightly weighted bonus skills
- `roadmap` — an ordered list of learning stages

`script.js`'s matching engine scores every career against your entered skills (exact + partial matches), normalizes to a 0–100% match, and ranks them. The top match drives the recommendation panel and the learning roadmap; the top 5–6 drive the career grid and gap chart.

### Extending the career database

Open `careerData.js` and add a new object to the `CAREER_DB` array:

```js
{
  id: "your-role-id",
  title: "Your Role Title",
  icon: "🚀",
  blurb: "One sentence describing the role.",
  coreSkills: ["skill one", "skill two"],
  niceToHave: ["bonus skill"],
  avgSalaryRange: "$XXk – $XXk",
  roadmap: [
    { stage: "Stage name", duration: "X weeks", focus: "What this stage covers" }
  ]
}
```

Skill strings should be lowercase — display formatting is handled automatically.

---

## 🎨 Customizing the design

All design tokens live at the top of `style.css` under `:root` and `[data-theme="light"]` — colors, fonts, spacing, and radii are all CSS custom properties, so reskinning doesn't require touching layout rules.

```css
:root {
  --accent-violet: #7c5cff;
  --accent-cyan: #3ddad7;
  --font-display: "Space Grotesk", sans-serif;
  --font-body: "Inter", sans-serif;
  /* … */
}
```

---

## 🛠️ Tech notes

- **No framework** — vanilla JS, ES modules not required (works via plain `<script>` tags)
- **PDF export** — [jsPDF](https://github.com/parallax/jsPDF) loaded via CDN, builds the report directly from the last analysis run, entirely client-side
- **Fonts** — Space Grotesk (display), Inter (body), JetBrains Mono (data/labels) via Google Fonts
- **No tracking, no analytics, no external API calls** — what you type never leaves the page

---

## ⚠️ Disclaimer

This tool offers illustrative career guidance based on a simple, transparent scoring model — it is not professional career counseling and salary figures are approximate. Use it as a starting point for your own research.
